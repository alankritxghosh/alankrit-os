- X follower count

- Substack subscriber count or first-post status

1. Use the approved milestone table in `BRAND_AGENT_POLICY.md`.

3. Compare current counts with the next checkpoint.
4. Do not explain changes with guesses.
5. If input gates or checkpoints are missed for two weeks running, tell Alankrit to revisit the plan.

Output:

- checked date
- next checkpoint
